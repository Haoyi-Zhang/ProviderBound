# Inference and validity contract

## Target quantity

For each normalized archive entry and caller-supplied label function, the method returns the exact set of labels that can own the first provider consistent with all supplied global-order constraints and observed output bytes. An empty feasible-order set is evidence inconsistency, not attribution ambiguity.

## Units and frames

The formal unit is an entry within a finite provider set. The paired public study unit is an unordered pair from a preserved 107-archive frame; all 5,671 pairs are enumerated. The multi-provider unit is a retained connected conflict group, for which every provider permutation is built. The scale study is a constructed workload.

## Descriptive versus generalizable statements

Counts and percentages from the frozen public frame are descriptive finite-population results. They do not estimate Maven, Android, Java, Debian, or software ecosystems. Semantic conformance statements are conditional on the stated model and inputs. Mathematical soundness/completeness statements range over the formal language, not over transformations excluded from that language.

## Information baselines

1. **Output-content only:** sees entry path and bytes but no winning-provider history. Equal-byte providers are observationally indistinguishable.
2. **Local candidates:** applies first-winner reasoning independently per entry. It is an over-approximation because different entries must share one global provider order.
3. **Known complete order:** identifies a unique first provider whenever a candidate exists, but changes the problem by supplying the hidden variable.
4. **Literal permutation oracle:** enumerates the same feasible-order language and is used only where the provider count makes enumeration practical.

Unrelated library detectors, package managers, SBOM generators, and legal-attribution systems are discussed as adjacent work, not scored as if they accepted the same evidence and produced the same object.

## Validity claims not made

The work does not establish that the preserved frame is representative, that all real build systems implement the model, that provider lists are complete, that labels encode real authorship, or that certificate replay makes the original evidence truthful. These are explicitly outside the estimand.
