# Native archive and owned Java replay

This Windows execution used CPython 3.12.14 and Temurin OpenJDK/javac
21.0.12.1. The same 43 public provider JARs and Ant 1.10.15 builder JARs are
retained under the original input inventory and licenses.

`public/` records 80 actually executed Ant builds over 40 pairs, their per-build
counts, all scientific summary fields, raw builder diagnostics and three saved
representative graph/certificate/answer triples. All 165,630 regional outcomes
agree with the two-order oracle. Temporary full output ZIPs are not part of this
record; their digests and counts are in `cases.csv`, and reproduction rebuilds
them. This is the same frozen corpus, not 80 new independent projects.

`java/` retains the exact owned provider/output JARs, input/certificate pairs,
source files, and all five compiler/probe command stream bytes and exit records.
`java_summary.json` reports the two opposite-order observations, 11 and 22.
These are owned integration fixtures, not an Android pipeline or native
third-party analyzer deployment. Child CPU/RSS and aggregate Java CPU remain
unavailable on this Windows path; no zero value substitutes for them.

Per-JAR and Debian-package inference results are in the separate current
`diagnostics/` collection. The package-level and developer-policy gains remain
zero on the public all-library corpus. The reported native timings are not
compared with historical Linux times as an optimization result.
